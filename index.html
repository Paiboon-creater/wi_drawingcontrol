บริษัท จากัวร์ อินดัสตรีส์ ( ประเทศไทย) จำกัด วิธีปฏิบัติงาน : การควบคุม Drawing
ที่อยู่ 22 ถนนบางแวก แขวงคลองขวาง เลขที่เอกสาร WI-MO-001 แก้ไขครั้งที่ 00
เขตภาษีเจริญ กรุงเทพฯ 10160 วันที่บังคับใช้ 10/10/2560 หน้าที่ 2 / 2
1.0     คำจำกัดความ
1.1 Drawing หมายถึง แบบของผลิตภัณฑ์เครื่องครัวฯ
2.0     วิธีปฏิบัติงาน
2.1     จัดทำบัญชีรายการ Drawing
2.1.1    จัดทำบัญชีรายการ Drawing (F-MO-007) เพื่อใช้กำหนดเลขที่ของ Drawing และ
           ใช้ควบคุมลำดับการแก้ไข เพื่อป้องกันการใช้เอกสารเก่ามาใช้งาน
2.2     การแจกจ่าย Drawing
2.2.1    ทำการแจกจ่ายเอกสาร (Drawing) ไปตามแผนกและผู้ที่เกี่ยวข้อง โดยทำการ
           บันทึกลงในใบควบคุมการแจกจ่าย Drawing (F-MO-008) และให้ผู้ที่ใช้เอกสาร
           เซ็นต์ชื่อ/วันที่ลงในช่องแจกจ่าย
2.3     การแก้ไขและการเรียกเก็บ Drawing
2.3.1    ในกรณีที่มีการแก้ไข Drawing ให้ทำการบันทึกโดยการทำเครื่องหมายถูกลงใน
           บัญชีรายการ Drawing (F-MO-007) ในช่องลำดับการแก้ไข
2.3.2    ในกรณีที่มีการแก้ไขให้ทำการเรียกเก็บ Drawing โดยใช้ใบควบคุมการแจกจ่าย
           Drawing (F-MO-008) ติดตามเอกสาร และให้ผู้ที่ใช้เอกสารเซ็นต์ชื่อ/วันที่ลงใน
           ช่องรับคืน เพื่อป้องกันการนำเอา Drawing เก่ามาใช้งาน
3.0 เอกสารที่เกี่ยวข้อง
3.1 บัญชีรายการ Drawing (F-MO-007)
3.2 ใบควบคุมการแจกจ่าย Drawing (F-MO-008)
3.3 แบบฟอร์ม Drawing (F-MO-009)
ส่วนที่ 1: บัญชีรายชื่อ Drawing (F-MO-007-00) — ดึงรายชื่อไฟล์จากโฟลเดอร์ design (กำลังโหลด...)
ส่วนที่ 2: ใบแจกจ่าย Drawing (F-MO-008-00)
